# SAINTFOUR RAP BATTLE ’27 — Telegram Mini App

Мобильный сайт и будущий Telegram Mini App проекта Gossip Saintfour.

## Стек
- React 19, Vite
- CSS без платных зависимостей
- lucide-react для иконок
- Официальный Telegram WebApp JS bridge

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Разделы
Главная, карточки четырёх рэперов, медиатека с фильтрами и видео-модальным окном, фотогалерея, анонсы, опросы, раздел спонсоров.

## Спонсоры
Компонент `src/Sponsors.jsx` содержит три бренда вселенной фан-проекта: WARLOCK (генеральный партнёр), BLACK HOLE ENERGY (энергетик шоу) и GOSSIP SAINTFOUR / «Сплетница Сентфора» (медиа-партнёр, автор проекта). В карточках используются текстовые надписи, а не утверждённые логотипы; их можно заменить на готовые материалы. Оформление в `src/sponsors.css`.

## Загрузка изображений и видео
Имена изображений прописаны в `src/App.jsx`. Добавьте файлы в `public/media/`:
- `lil-dex.jpg`, `mc-netti.jpg`, `rudi.jpg`, `don-daro.jpg`
- `interview-dex.jpg`, `interview-netti.jpg`, `teaser.jpg`
- `gallery-01.jpg` … `gallery-04.jpg`

До загрузки файлов работают авторские графические заглушки. В `media` укажите настоящий URL видео только после его публикации.

## Важное о голосовании
**Демонстрация, не реальное голосование.** Выбор записывается в localStorage только на текущем устройстве. Никаких общих результатов, антинакрутки или серверной базы пока нет. Для реальных голосов требуется сервер + проверка подписи Telegram initData на сервере. Нельзя доверять `initDataUnsafe` как доказательству личности.

## Telegram Mini Apps
В `index.html` подключён официальный WebApp JS. Приложение вызывает `ready()`, `expand()` и задаёт цвета, если открыто внутри Telegram. В обычном браузере работает самостоятельно.

После согласования публикации: разместить HTTPS-сайт на бесплатном хостинге и привязать его URL к боту через BotFather. Не вставляйте bot token в код клиента, конфигурации Vite или репозиторий.

## Статус
Локальный прототип. Без опубликованных медиа, без настоящего голосования и без публичного деплоя.
