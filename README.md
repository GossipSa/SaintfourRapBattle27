# SAINTFOUR RAP BATTLE ’27 — Telegram Mini App

Мобильный сайт и будущий Telegram Mini App проекта Gossip Saintfour.

## Стек
- React 19, Vite
- CSS без платных зависимостей
- lucide-react для иконок
- Официальный Telegram WebApp JS bridge

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Разделы
Главная, карточки четырёх рэперов, медиатека с фильтрами и видео-модальным окном, фотогалерея, анонсы, опросы, раздел спонсоров.

## Бегущая строка под главным экраном
На главной между первым экраном и блоком участников работает непрерывная бегущая строка с оригинальными слоганами: NO RULES ✳ NO FILTER ✳ NO MERCY ✳ SAINTFOUR RAP BATTLE ’27. Строка с именами рэперов удалена. Реализация в `src/LineupMarquee.jsx` и `src/lineup-marquee.css`. При настройке уменьшенного движения анимация отключается.

## Спонсоры
Компонент `src/Sponsors.jsx` содержит три бренда вселенной фан-проекта: WARLOCK (генеральный партнёр), BLACK HELLEBORE ENERGY (энергетик шоу) и GOSSIP SAINTFOUR / «Сплетница Сентфора» (медиа-партнёр, автор проекта). В карточках используются текстовые надписи, а не утверждённые логотипы; их можно заменить на готовые материалы. Оформление в `src/sponsors.css`. Карточки открываются в отдельном модальном окне поверх страницы по кнопке «Открыть карточку», не увеличивая высоту раздела: для канала есть ссылка `https://t.me/Gossip_Saintfour`; для BLACK HELLEBORE ENERGY есть описание и вкладки «Фото / Видео». Добавьте настоящее фото банки как `public/media/sponsors/black-hellebore.jpg`, а рекламный ролик как `public/media/sponsors/black-hellebore.mp4`. До добавления файлов отображается декоративный концепт банки с пометкой `MEDIA COMING SOON`, не выдуманное фото или видео. Для WARLOCK есть информационная карточка о компании.

До загрузки файлов работают авторские графические заглушки. В `media` укажите настоящий URL видео только после его публикации.

## Важное о голосовании
**Демонстрация, не реальное голосование.** Выбор записывается в localStorage только на текущем устройстве. Никаких общих результатов, антинакрутки или серверной базы пока нет. Для реальных голосов требуется сервер + проверка подписи Telegram initData на сервере. Нельзя доверять `initDataUnsafe` как доказательству личности.

## Telegram Mini Apps
В `index.html` подключён официальный WebApp JS. Приложение вызывает `ready()`, `expand()` и задаёт цвета, если открыто внутри Telegram. В обычном браузере работает самостоятельно.

После согласования публикации: разместить HTTPS-сайт на бесплатном хостинге и привязать его URL к боту через BotFather. Не вставляйте bot token в код клиента, конфигурации Vite или репозиторий.

## Статус
Локальный прототип. Без опубликованных медиа, без настоящего голосования и без публичного деплоя.
